Features

Small app, specific job.

Everything here answers one question well: is an agent working right now, and should this Mac stay up for it?

Awake only for your agent

The Mac stays up only while a watched agent is actually working. An agent sitting idle at a prompt, waiting on you, gets no wake lock at all, and your machine sleeps like it normally would.

Real state, via hooks

Lifecycle hooks report working and idle per session, so HoldMyCode knows the difference between a busy agent and a process that merely happens to be running.

Battery guardrails

Set a percentage where the hold gives up, or restrict holds to when you're plugged in. Low Power Mode is respected rather than fought.

Display control

Coming soon

Planned: choose whether the display sleeps on lid close, dims while the agent runs, or shuts off a set number of seconds after the work finishes. Not in the app yet.

Notifications

A banner, and an optional sound, when a hold starts, when it ends, and when your battery threshold cuts it short. You're never left guessing what the Mac decided behind your back.

Menu bar dropdown

Live status, elapsed hold time, battery level, the keep awake mode and a master toggle, all one click from the menu bar. You can pause it for half an hour, and there's a global hotkey too, for when reaching for the mouse feels like too much.

Claude usage in the panel

New in 2.0

The panel shows your Claude Code limit windows, how much of the session is left, today's turns, and an estimated cost. The figures are the ones Claude Code reports. Where it reports nothing, the panel shows nothing rather than a guess.

Limit countdown in the menu bar

New in 2.0

While Claude is refusing turns because a usage limit was hit, the menu bar icon counts down the time left until the window lifts. You know when to come back without opening anything.

What's new in 2.0

Claude's usage in the panel, and hooks that set themselves up.

2.0 brought Claude's usage figures into the panel and took the manual work out of hooks and updates. 2.0.1 followed by making the figures honest.

  1. Claude usage in the menu bar panel

    The current limit windows, how much of the session is left, today's agent stats, and an estimated cost. The numbers come from Claude Code's own reporting. Earlier builds inferred a percentage from local logs and could read "114% used", so that estimate was removed: where Claude Code reports nothing, the app shows nothing.

  2. A usage limit counts down in the menu bar

    While Claude is refusing turns over a limit, the icon shows the time left until the window lifts.

  3. A limit that has lifted stops being reported

    A limit hit this morning is no longer shown as a live warning tonight. One limit that was retried several times is counted once, not once per retry.

  4. Hooks install themselves

    Every supported agent on your Mac is hooked up at launch and kept up to date, including an agent you install later. Nothing to click and nothing to paste into a config file. One exception, stated honestly: Cline's config lives inside ~/Documents, which triggers a macOS permission prompt, so Cline's hooks are offered rather than installed silently.

  5. One-click updates

    When a new version is out, press Update. The app downloads it, swaps itself in and reopens. No browser, no dragging to Applications. The browser download stays as a fallback if that fails.

  6. A What's New window

    After an update installs, the app opens a short page explaining what the new version changed, so an update never arrives unexplained.

2.0.1 smaller fixes

  • The app asks your shell where Claude Code is installed instead of guessing, so version managers (nvm, fnm, mise, asdf) work.
  • Usage refreshes every minute in the background, rather than only while the panel is open.
  • A usage reading that hangs is abandoned and retried instead of freezing the panel.
  • The currency for the cost estimate is picked in Settings.

FAQ

Reasonable questions.

How is this different from Caffeine or Amphetamine?

Those keep your Mac awake for as long as you leave them switched on. The decision is yours, and the classic failure mode is forgetting to flip it off, then finding a hot, flat laptop at the bottom of your bag. HoldMyCode ties the wake lock to the agent instead. The hold exists only while a watched agent is in the middle of a task, and it ends by itself when the work does. Nothing to toggle, nothing to forget.

Does it really keep running with the lid closed and no external display?

Yes. A plain sleep assertion isn't enough for a lid close, so HoldMyCode installs a small privileged helper that disables lid sleep while a hold is active and turns it back on the moment the hold ends. No external display, keyboard, or dongle required. macOS asks you to allow it once, in System Settings under Login Items.

Can it read my code or my prompts?

No. It never reads your code or your prompts, and nothing about your sessions leaves your Mac. Hooks record only whether a session is working, in a small file on your Mac. The usage card counts turns and estimates cost from Claude Code's own local files and asks Claude Code itself for your limit figures; that runs on your Mac and sends nothing anywhere. The app has no account and no analytics inside it. It talks to exactly two servers: GitHub, to check for and download a new version, and, if you leave local currency switched on, a public exchange rate feed once a day, which is sent nothing about you. The only other part that talks to a server is this website, which keeps an anonymous download count and the email address you give before downloading.

Which agents work today?

Claude Code, Codex, Gemini CLI, Cursor and Cline through their lifecycle hooks. Since 2.0 those install themselves: every supported agent found on your Mac is hooked up at launch and kept up to date, and so is one you install later. Cline is the exception, because its config sits in ~/Documents behind a macOS permission prompt, so it asks first. Claude Cowork works out of the box from the Claude app's task logs. You can still remove hooks in Settings › Agents, and nothing puts them back.

What stops it from draining my battery?

A threshold you pick. Below it, the hold releases and a notification tells you why. You can also restrict holds to times when you're on power, and HoldMyCode won't override Low Power Mode. Thermal pressure ends a hold too, rather than cooking the machine in a bag.

Is it actually free, or free for now?

Free. No licence key, no trial timer, no surprise paid tier waiting in the wings. It's a small utility that does one job, and charging for it isn't the plan. The app is closed source, so that's a promise rather than something you can audit, but there's no account to create and nothing to cancel.
